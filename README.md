# Rashed Azizi Portfolio

A minimal developer portfolio built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Tech Stack

- Next.js 15 App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- React Icons

## Pages

- Home
- Blog
- Impossible List
- CV
- Supporting legacy routes for About, Projects, Experience, Education, and Contact

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm run start
```

The project is configured for standard Vercel deployment.
